# 🚀 QUICK START GUIDE - Village of Dragons

## Installation (2 Minutes)

### Step 1: Download & Install

**Option A: APK File**
1. Download `VillageOfDragons.apk`
2. Transfer to phone
3. Tap to install
4. Allow permissions
5. Launch game

**Option B: Google Play Store** (Coming soon)
1. Search "Village of Dragons"
2. Tap "Install"
3. Wait for download
4. Tap "Open"

### Step 2: First Launch

1. ✅ Allow storage permission
2. ✅ Allow Bluetooth (for multiplayer)
3. ✅ Enter player name
4. ✅ Watch tutorial
5. ✅ Start playing!

## First 5 Minutes

### Minute 1: Understand the Interface

```
Top Left:  Resources (Gold, Elixir, Gems)
Top Right: Player Level & Town Hall Level
Bottom:    Action Buttons (Build, Attack, Army, Shop, Settings)
Center:    Your Village
```

### Minute 2: Collect Resources

1. Tap **Gold Mine**
2. Tap **"Collect"** button
3. See gold increase
4. Do same for **Elixir Collector**

### Minute 3: Build Your First Building

1. Tap **"Build"** button
2. Select **"Barracks"** (army building)
3. Drag to place on village
4. Tap **"Build"**
5. See construction starting

### Minute 4: Train Your First Troops

1. Tap on **Barracks** building
2. Tap **"Train Troops"**
3. Select **"Barbarian"**
4. Enter quantity: **10**
5. Tap **"Train"**
6. Wait 5 seconds

### Minute 5: Prepare for First Attack

1. Tap **"Attack"** button
2. Select enemy village
3. Tap **"Attack"**
4. Deploy your 10 barbarians
5. Watch them fight!

**What to do:**
- ✅ Build Gold Mines (more income)
- ✅ Upgrade storage (hold more)

**What to do:**

## Battle Tips for Beginners

### Before Attack

1. **Scout the village**
   - Look for weak spots
   - Identify defenses
   - Plan troop placement

2. **Check your army**
   - Do you have enough troops?
   - Right troop type?
   - Heroes ready?

3. **Plan strategy**
   - Which side to attack?
   - Where to deploy first?
   - When to use spells?

### During Attack

1. **Deploy troops wisely**
   - Start with tanks (Giants)
   - Follow with damage (Dragons)
   - Support with spells

2. **Use spells effectively**
   - Healing spell = restore health
   - Rage spell = increase damage
   - Freeze spell = stop defenses

3. **Watch the timer**
   - You have 3 minutes
   - Don't rush
   - Plan carefully

### After Attack

1. **Check results**
   - Victory? Get trophies & resources
   - Defeat? Learn from it
   - Watch replay

2. **Collect loot**
   - Gold goes to storage
   - Elixir goes to storage
   - Use for upgrades

## Troop Types Guide

### Basic Troops (Early Game)

**Barbarian** 💪
- Fast, melee damage
- Good for learning
- Level up for stronger attacks

**Archer** 🏹
- Range attacker
- Good support
- Decent damage

**Giant** 🗻
- Tank unit
- Absorbs damage
- Protects other troops

### Advanced Troops (Mid Game)

**Dragon** 🐉
- Air unit (flies over walls)
- Strong damage
- High cost
- Very useful

**Wizard** 🧙
- AOE damage (area)
- Destroys groups
- Good support

**PEKKA** 💥
- Very strong
- Melee attacker
- Costs lot of elixir

## Troubleshooting

### Game Won't Launch

**Solution:**
1. Check storage space (need 500 MB)
2. Restart phone
3. Uninstall & reinstall app
4. Check permissions

### Can't Connect Multiplayer

**Solution:**
1. Both on same WiFi
2. Enable Bluetooth
3. Pair devices
4. Restart app
5. Try again

### Resources Not Generating

**Solution:**
1. Check building levels
2. Collect manually
3. Restart game
4. Check storage isn't full

### Save Data Lost

**Solution:**
1. Check if file exists: Settings → Storage
2. Restore from backup
3. Start new game
4. Use Developer Mode to progress fast
