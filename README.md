# 🐉 VILLAGE OF DRAGONS - Android Strategy Game

**A Complete Clash of Clans-style Strategy Game with Dragons!**

---

## 📱 Game Overview

**Village of Dragons** is an offline Android strategy game combining:
- 🏰 Clash of Clans gameplay mechanics
- 🐉 Dragon collection & breeding system
- ⚔️ Multiplayer battles (Bluetooth/WiFi)
- 📈 Town Hall progression (Level 1-100)
- 💰 Complete resource management
- 🎮 Engaging combat system

---

## 🚀 Quick Start

1. **Clone Repository:**
   ```bash
   git clone https://github.com/hih569950-byte/village-of-dragons.git
   ```

2. **Open in Unity:**
   - Unity 2022 LTS or newer
   - Android Build Support

3. **Build for Android:**
   - File → Build Settings
   - Select Android platform
   - Build & Run

4. **Activate Developer Mode:**
   - Settings → Developer Mode
   - Password: `jaripraj`
   - Unlock unlimited resources

## 🎮 How to Play

1. **Start Game** - Create village
2. **Build Base** - Place buildings strategically
3. **Collect Resources** - Gold & Elixir generation
4. **Train Troops** - Develop your army
5. **Hatch Dragons** - Collect dragon eggs
6. **Upgrade Everything** - Level up buildings, troops, heroes
7. **Attack Others** - Battle enemies for loot
8. **Defend Village** - Protect from attacks
9. **Progress Town Hall** - Unlock new content
10. **Reach Level 100** - Ultimate endgame!
